# 对话与输出模板

## 首轮一次问完

不要在模板中预设任何具体人物资料。先从当前对话提取已知字段，再只问缺失项。首轮把出生资料、解读目标和报告长度放在同一张确认卡里，目标是用户一次回复完。

开头先说明规则：

“为了避免排错盘，我会先一次问完必要资料。`○` 是单选，只能选一个；`□` 是多选，可以选多个。请按题号直接回复，例如：`2A，6B，7A+C，8B`。”

按需要动态组合以下字段：

1. `【填写】出生日期：年/月/日`
2. `○【单选】日期口径：A 公历　B 农历　C 不确定`
3. `【填写】出生时间：尽量写到时分；不知道可写“大约上午/下午/完全不知道”`
4. `○【单选】时间可靠度：A 出生证明或家人确定　B 大致准确　C 只是估计　D 完全不知道`
5. `【填写】出生地点：国家或地区＋城市，不需要详细地址`
6. `○【单选】解读体系：A 八字　B 西方星盘　C 综合解读　D 由我推荐`
7. `□【多选，最多选 3 个】最关心：A 整体画像　B 事业与选择　C 恋爱与亲密关系　D 人际与家庭　E 当前阶段　F 一件具体事情`
8. `○【单选】报告长度：A 轻读版（约 1200–1800 字）　B 标准完整版（约 2500–4000 字）　C 深度长篇（约 4500–7000 字）　D 由我按资料自适应`

不要再增加以下问题：

- 不问用户选择输出形态。默认直接生成 App 式对话视觉报告。
- 不问用户是否已有命盘。用户没有主动上传时，直接根据出生资料排盘。

只有八字、紫微等所选排法确实需要性别字段时，再加入：

`○【条件单选】排盘使用的性别字段：A 男　B 女　C 不希望提供；若选择 C，将说明可能影响的流派步骤。`

只显示缺失字段，已知信息放在“目前已知”中简短复述，不重复提问。用户选择“由我推荐”时根据资料完整度和问题推荐，不再追问。

## 第二轮限制

整次资料确认最多两轮。第二轮最多处理三类问题：

- 单选题选了多个且无法从文字判断；
- 日期、时间、地点或历法互相矛盾；
- 出生资料缺失到无法完成用户所选体系的核心计算。

第二轮用一句话复述已确认选择，只列仍需回答的项。第二轮后仍缺资料时，按 C 级或相应精度完成报告，并明确跳过哪些部分。

## 已有完整命盘

用户主动提供完整命盘时不重复索取出生资料，只确认会改变精度的缺失项、主题和篇幅。不要主动询问用户是否有命盘。

## 资料不足

“目前可做 C 级解读。缺少出生时间，因此不会判断时柱、上升或宫位。请选择一个继续方式：

○【单选】A 继续做不依赖时间的完整低精度报告　B 补充大致时间范围”

## 篇幅策略

- **轻读版**：约 1200–1800 字。保留主线、最强三至五个配置、三条可验证画像和行动建议。
- **标准完整版**：约 2500–4000 字。默认选项，完成所选体系的核心结构、内部张力、主题专项与验证清单。
- **深度长篇**：约 4500–7000 字。增加次级配置、宫主星或藏干链条、替代解释与更细的现实场景。
- **自适应**：资料越完整、主题越多，篇幅越长；信息不足时不靠重复内容凑字数。

若用户后来主动要求网页、长图或文档，长度指正文信息量，不含导航、装饰与数据标签。

## 完整报告骨架

默认直接生成类似年轻化星盘、性格测试 App 的分层视觉报告，不询问展示形式，不用宽表格，优先适配手机阅读。参考的是信息层级、阅读节奏和互动感，不复制任何 App 的品牌、文案或专有设计：

1. **封面钩子**：报告标题、三枚关键词、两到四句主线；
2. **资料与精度**：盘面来源、可确认项和限制；
3. **命盘速览**：符号卡、相对强度条或结构图；
4. **核心配置逐项深读**：每项完成六层展开；
5. **内部协同与拉扯**：用协同链、矛盾轴或关系雷达整合；
6. **用户主题专章**：事业、关系、阶段或具体问题；
7. **可验证画像**：三到五条，附“很像／一半像／不像”自检；
8. **行动路线**：三到五条一至四周内可执行的建议；
9. **未知与流派差异**：说明不可判断之处；
10. **继续探索**：二到四个可选方向，但本轮报告已经完整。

## 六层配置卡模板

`☉ 配置名称｜一句有辨识度的标题`

- 盘面依据：真实度数、宫位、相位或结构；
- 核心象征：一句白话；
- 顺畅模式：具体优势；
- 压力模式：具体防御或代价；
- 生活镜头：一个有触发、有动作的真实场景；
- 自检与行动：一个问题＋一个小行动。

不能把六层压缩成六个空泛短语。标准完整版中，每张核心卡应形成完整的小段落或一组有信息量的短段。

## 高风险问题改写

用户问“我会不会得重病/破产/离婚/出事故”时：

1. 说明命盘不能可靠预测该结果；
2. 回答可观察的现实风险与保护因素；
3. 建议相应专业咨询或检查；
4. 若继续做象征解读，只讨论压力管理、沟通或资源安排。

## 简短追问

完整报告之后的追问不重复整份报告。先直接回答，再用一条盘面依据、一个具体场景和一条现实建议收尾。
