# 八字解读指南

## 输入要求

优先顺序：

1. 用户提供已经排好的四柱与大运表。
2. 可靠排盘工具返回四柱、起运时间和大运。
3. 用户只提供公历或农历出生资料，此时不要凭记忆保证排盘准确。

需要说明：公历/农历、出生日期、当地时间、出生城市、时间是否准确。不同流派可能采用真太阳时、早晚子时、节气换月等不同规则；未核实时标为未知。

## 解读顺序

1. **日主**：日柱天干，传统上用来代表命主的观察中心，不等于完整人格。
2. **月令与季节**：判断五行在出生季节中的相对状态。
3. **五行结构**：观察木火土金水的分布、流通与明显偏向。不要把数量简单等同于强弱。
4. **十神关系**：用于描述资源、表达、规则、关系与财富等象征角色。解释时回到行为和情境。
5. **组合关系**：合、冲、刑、害、会局等只能作为结构变化线索，不能直接等同于吉凶事件。
6. **大运与流年**：只有在起运年龄和运表可靠时讨论。先说主题窗口，再说可能表现和现实条件。
7. **用神或喜忌**：不同流派判断可能不同。写明采用的逻辑，不把单一结论当成绝对答案。

## 白话映射

| 传统术语 | 可用的白话方向 |
|---|---|
| 比劫 | 自我主张、同辈竞争、合作与边界 |
| 食伤 | 表达、创造、输出、挑战规则 |
| 财星 | 资源交换、结果意识、关系投入 |
| 官杀 | 规则、压力、责任、外部评价 |
| 印星 | 学习、支持、内在安全、方法体系 |

这些是解释框架，不是人格诊断。每个十神都可能有建设性和受压表现。

## 禁止的简化

- 不用“五行缺什么就补什么”替代完整分析。
- 不按生肖、单一日主或某一个神煞直接下结论。
- 不把“冲”直接解释为离婚、事故或死亡。
- 不把“财”直接等同于一定发财，也不把“官杀”直接等同于官职或灾祸。
- 不在没有可靠大运表时预测具体年份。

## 推荐输出

先给结构主线，再分别解释优势、压力点和调节方式。每项结论引用相应四柱、五行或十神依据，并给出至少一种现实中的替代表现。
