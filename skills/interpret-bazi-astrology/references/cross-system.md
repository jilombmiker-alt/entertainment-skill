# 跨体系综合指南

跨体系解读的目标是寻找可供反思的共同主题，不是用多个体系制造“多重验证”的假象。

## 综合步骤

1. 分别完成每个体系的独立解读。
2. 用并列卡片列出：体系、可确认盘面、象征主题、现实观察点、精度。移动端默认不用宽表格。
3. 只把语义真正接近的内容归为共同主题。
4. 对冲突结论保留差异，说明可能来自输入精度、流派或体系关注重点。
5. 最后给一组不依赖超自然因果的现实行动建议。

综合报告至少展示：共同主题、互补视角、明显冲突、冲突可能来自的精度或体系差异、现实中如何验证。不要简单把两个体系的结论各抄一遍。可用“共同信号强度条”和“内在张力图”帮助阅读，但必须注明它们表示本报告内的相对象征强调，不是科学评分或概率。

## 推荐表达

- “两个体系都把注意力指向边界与责任，但依据不同。”
- “这是主题上的相似，不代表事件经过了独立科学验证。”
- “八字侧重时间结构，星盘侧重心理与生活领域，两者在这里给出不同视角。”

## 避免

- 不用“中西命理都这么说，所以一定会发生”。
- 不为了制造一致性而忽略矛盾。
- 不把相似术语当成完全相同的概念。
