# 设计模式与原创边界

只把以下产品用作机制参考。不要复制其文字、路线、谜题、美术、角色、品牌语气或付费内容。

| 来源 | 可迁移原则 | 本 Skill 的改编方式 |
|---|---|---|
| Story City — https://about.storycity.app/inside-the-frightnight-story-every-choice-counts/ | 身份、分支选择和有状态结局 | 围绕经核验公共场所开展边界明确的 AI 对话 |
| Geocaching Adventure Lab — https://www.geocaching.com/sites/adventure-lab/ | 基于地点的关卡和灵活顺序 | 提供可选证据方式及保护隐私的替代方案 |
| Questo — https://questoapp.com/ | 地标观察与剧情推进结合 | 使用较短的自适应路线，不采用固定的付费任务 |
| VoiceMap — https://voicemap.me/ | 低屏幕占用、地点触发的叙事 | 使用紧凑剧情节点，每次只呈现一个关卡 |
| Goosechase missions — https://support.goosechase.com/en/articles/4437526-creating-your-missions | 照片、文字和位置任务类型 | 由玩家选择验证方式，所有方式都能获得同等质量的结局 |

本 Skill 的独特产品承诺是：经核验的城市事实 + 虚构的平行身份 + 能改变下一关的状态。必须保留三者，否则输出会退化为观光行程、寻物清单或纯角色扮演。
